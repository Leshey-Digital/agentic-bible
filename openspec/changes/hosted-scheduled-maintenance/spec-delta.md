# Added requirements

- An unconfigured/disabled scheduled action performs no source, generation or publication effects.
- A trusted server selection binds the exact schedule, compiled article identity, source profiles and expected revision. Request bodies cannot expand authority.
- Complete native generation binds charged original acquired bytes, extraction identity and the existing currency/generation ledger. Malformed output remains charged and cannot automatically redispatch.
- A new source-backed structural provenance is distinct from fixtures and does not grant publication authority. Generic/manual/legacy producers reject it.
- Eligible native publication requires exact current source, generation, candidate, predecessor and quality authority. A serialized or fabricated capability cannot authorize publication. Restart must re-read retained authority.
- Known quality denial preserves source/provider charges and has no publication effect. Unknown source/provider/verifier outcomes remain held with no automatic retry.
- Completed retry returns retained receipts without new collection, generation, verification or publication operation. A lost publisher response uses the existing publisher replay contract and preserves immutable revision history.
- Existing post-publication flags remain; no universal human preapproval is introduced and no correction-note approval boundary is bypassed.

# Acceptance

Use mocked external source and AI responses with actual local D1 and the existing isolated publisher. Verify closure, source/currency admission, native complete JSON, exact quality, opaque admission, forgery rejection, flags/history, denial, uncertainty, conflicts and restart/replay. No real provider, GitHub or deployment request is evidence from these checks.

- Native canonical publication MUST bind the exact base Git commit, original Markdown hash and expected article predecessor into the charged complete-generation prompt, proposal and opaque admission.
- Canonical writes MUST use the existing bounded writer outbox and expected-head mutation, append immutable version 3 history and the review pointer atomically, verify all resulting Git leaves, and hold uncertain outcomes without mutation redispatch.
- Removing source authority while dispatch or local activation is held MUST prevent the subsequent effect while retaining source/provider charges.
- Current schema 1/2 records remain readable; version 3 native records and review catalogs are admitted explicitly, without widening compiled targets or inventing human preapproval.
- The portable native path MUST execute in actual workerd/D1 with mocked external dependencies, and its canonical Git tree MUST build the existing reader/search/history inventory.

- Registered source profile bounds MUST remain available end to end. Raw bodies above legacy32KiB limits MUST be privately retained/reconstructed under the registered per-source cap; full raw bodies MUST NOT enter Git/public output/provider prompts. SQL, chunks, captures and event/source counts remain finite.
- Missing capture schema MUST stop readonly before any job admission or source/model effect. Partial, corrupt and unknown captures MUST NOT silently refetch or regenerate.
- Quality v2 MUST require explicit verifier format support and actual charged source/capture authority; absent extensions retain legacy request/receipt bytes.
- Native source-backed maintenance MUST bind a complete previous article body and full original Markdown hash to quality/generation, and verify the exact qualified canonical code/base before new source/model costs.
- A stale pinned operation MUST NOT silently rebase or spend on a new event; completed historical replay MUST NOT repeat external work.
- Native schemas MUST preserve signed post-publication review/explicit restoration and exact saved-environment release preparation safeguards.

Canonical generation and semantic assessment must recheck current baseline authority after durable monetary reservation, then refresh currency/time eligibility before inference. Completed receipt replay performs no new inference. An interrupted collected job must not charge a model against a stale canonical base.
