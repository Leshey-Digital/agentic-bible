# Semantic review requirements

- Trusted composition supplies an explicit current canonical body/hash/commit; mismatched prior context is rejected before inference.
- Source text and prior body are untrusted data. Assessment covers every claim and source under the existing strict report schema.
- Every paid assessment reserves the shared monetary ledger before dispatch. Repeated or ambiguous events cannot create another call.
- Neither a structurally valid article nor a model response grants canonical or deployment authority. Existing quality/admission gates remain in force.
- Tests use disposable local D1 and mocked model responses; they do not qualify live model quality or hosted publication.
