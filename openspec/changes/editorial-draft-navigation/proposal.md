# Preserve unsaved editorial work when switching suggestions

The existing hosted contribution inbox connects suggestions to dispositions, pinned-source review and GitHub draft proposals. Opening a suggestion currently resets the note/form without warning, losing work. Add an explicit discard confirmation when switching or reloading a suggestion with unsaved edits. Cancel retains the current item and fields; successful loading after explicit discard resets source/review authority. Edits entered during a pending detail read need the same protection.

This bounded continuation of the contribution-to-review milestone changes only private inbox navigation. No new storage, public intake, identity, paid calls, remote resource, publication or production deployment. Existing saved review receipts, uncertain retries, source pins and server authorization remain authoritative. The guard is not durable draft storage or protection for closing the tab. No new costs or product decisions are required.
