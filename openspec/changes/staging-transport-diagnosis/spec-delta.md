# Changed release transport requirements

- Generated upload/control capsules receive the existing lexical Cloudflare capability explicitly, without requiring or mutating a global property.
- Exact canonical-main Git reads retain the saved executor's existing proxy environment while excluding application credentials; expected source/target checks remain unchanged.
- Asset-upload HTTP 401 produces a token-free authorization error and zero implicit retries/version creation. Other unconfirmed failures retain their existing classification and bounds.
- Initial custom-domain attachment follows the first confirmed deployment. Full HTTPS verification and a successful durable receipt remain mandatory; initial TLS delay uses identical-plan reconciliation, never a journal/counter reset or a competing release.
- Keep provider session tokens opaque and within one execution. Do not infer signature validity from decoded claims, rewrite tokens, or claim a live authentication fix from controlled tests.
