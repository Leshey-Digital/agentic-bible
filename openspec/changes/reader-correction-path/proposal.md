# Honest reader correction path

The article currently invites readers to suggest corrections even though the public contribution form is closed. The noindex contribution page also renders the complete disabled form before runtime configuration is known, which can look like a supported public intake path.

Make the reader journey clear and useful while intake remains closed: article links lead to article-specific correction guidance, that guidance connects readers to the article's cited sources and revision record, and the page states that it cannot receive a reader report. Render the existing local or hosted form only after its existing status check explicitly enables that mode. Keep private editorial review limited to authorized editors.

This is a bounded reader-content and rendering change. It does not activate public intake, add email delivery or legal terms, change hosted authority, alter the twenty article files, expose private/admin pages, or change the existing noindex/canonical/sitemap policy. Rollback is a source revert with no data migration.
