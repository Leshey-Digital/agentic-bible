# Acceptance

- A signed admin with private inbox enabled and no GitHub credential reaches the inbox through /admin/.
- Disabled or unavailable maintenance catalogs render an honest unavailable page, without a save form or failing auto-load script; API validation remains closed.
- Private inbox navigation does not advertise GitHub corrections without runtime authority. Valid maintenance catalogs retain their existing review form and APIs.
- Anonymous and cross-site requests do not acquire admin access or a privileged redirect. Public intake, GitHub drafting and paid AI remain disabled.
- Verify the actual compiled module with the frozen disabled catalog, signed synthetic identity, local D1, and desktop/mobile keyboard navigation. No real editor or provider mutation occurs in tests.
