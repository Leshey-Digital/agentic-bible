# Bounded MCP source ingestion

The first authenticated staging draft stopped before inference because the official MCP HTML exceeded the existing 32 KiB raw limit. The UI obscured this terminal source rejection as an uncertain draft outcome.

Use an explicitly pinned official compact representation and a documented complete-section evidence profile while preserving raw receipts, byte spans, strict limits, citation provenance and token admission. Preserve existing HTML profiles and historical jobs. Report known pre-model failures truthfully; post-model uncertainty stays conservative. No global cap increase, silent truncation, remote reset, policy change, paid generation or publication is included.

The implementation will be qualified locally and independently reviewed before preparing a staging candidate. Existing staged authentication, bindings and rollback remain the runtime baseline.

Current implementation is limited to accurate source-failure reporting. The official compact Markdown URL was identified in the publisher index, but its direct fetch returned HTTP 403 and the documentation reader could not parse that MIME type. No body or headers were retained to distinguish origin rejection from environment restriction. No retry, alternate-route access, guessed section profile or registry expansion was performed. Compact ingestion remains unimplemented pending authorized access to exact source bytes for measurement.
