# Added local acceptance requirements

- AI agent explains a complete original action/observation trace, how it differs from a fixed workflow, and how to assess the result. Agent orchestration compares concrete arrangements and traces a revision-bound handoff. Claims have primary citations and scope; examples are labelled original/synthetic.
- With no compiled recorder installation, page/search/contribution/error hooks retain and transmit no measurement data.
- Explicit installation still requires current consent, approved origin, no DNT/GPC opt-out and a known public route. Revocation takes effect before the next event. Staging, admin/API/unknown paths and query/hash-bearing path arguments fail closed.
- Only finite event enums, canonical article IDs, route, UTC day and schema are accepted. Extra fields are rejected. A page admits at most 32 events; uncertain sink failure stops without retry. Disposable aggregate preview holds at most 128 cells and 10,000 events per cell.
- Search outcomes describe current completed searches and selection, not unique users or search relevance. Contribution closure, rejected save and unconfirmed save are distinct. Unavailable/corrupt status is an error, not proof that intake is closed.
- Controlled browser tests exercise actual search and contribution scripts with local static assets and fake API responses. They do not establish live collection, authenticated acceptance or paid inference.
