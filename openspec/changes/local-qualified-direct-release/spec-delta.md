# Changed release requirements

- GitHub Actions is not a required build/test/artifact/release service. No executable Actions workflow or automatic trigger remains; retained local commands cover every previous check.
- Saved-environment qualification requires exact clean source before/after each stage, successful full commands, bounded logs with hashes, measured toolchain/browser and an immutable candidate. Failure cannot mint a successful record.
- Independently reviewed qualification/candidate/source pins and explicit owner/exclusive-writer confirmation gate promotion. Checksums do not authenticate an untrusted executor.
- Preserve fixed account/Worker/staging origin, noindex and closed live ports, expected-active preflight, bounded markers/reconciliation, complete serving verification, durable journals/receipts and exact retained-version rollback.
- Existing connector authority stays server-side. Asset/completion JWTs never leave their execution. Verify full inventory bytes separately from provider asset IDs; preserve special header modules and binary contents.
- Pending connector requests are bound to a live local lease and exact code digest. Do not execute stale requests or automatically retry an ambiguous effect.
- No Workers Builds, new secrets, account security changes or production deployment is implied by this replacement.
