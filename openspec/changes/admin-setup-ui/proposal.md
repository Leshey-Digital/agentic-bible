# Admin setup UI

The existing hosted inbox reviews contributions and creates saved correction proposals, while integration settings expose only GitHub and raw connection enums. Extend the existing surface with fixed GitHub and Typesafe Jev choices, write-only credential replacement, explicit connection evidence, and server build status. Connect the inbox to setup and publication context.

Reuse the existing signed-admin routes, encrypted vault and controlled browser composition. No new framework, live identity, credential, billing, infrastructure or deployment is added. Jev is a structured decision model; no prose generation is implied. No non-billable Jev check is documented, so that action remains disabled. Actual credentials and approved finite currency caps remain owner setup.

A stored secret does not prove provider access. Controlled adapter success must be labeled controlled, and absent evidence remains unverified. Build-manifest identity does not prove live production serving. Failed writes retain uncertainty and require masked status reload before another attempt.
